# MegaBuffer / МегаБуфер

The clipboard that remembers. Images, screenshots and text you copy wait right at your cursor (Ctrl + Alt + V); drag anything into the app you need as a file. Windows 10 and 11, x64, free.

**Download:** [MegaBuffer-Setup.exe](https://github.com/aktivnjygomes-a11y/MegaBuffer-releases/releases/latest/download/MegaBuffer-Setup.exe) (latest version) · [all releases](https://github.com/aktivnjygomes-a11y/MegaBuffer-releases/releases) · [Microsoft Store](https://apps.microsoft.com/detail/9NDD5CTKLJQR)

The installer is not code-signed yet, so Windows may warn about an unknown publisher: click **More info → Run anyway**. Each release lists the SHA-256 of its file. The installer version does not update itself; download a new version from here.

The app makes no network requests, has no accounts and no analytics. [Website](https://megabuffer.app) · [Privacy policy](https://megabuffer.app/privacy) · Questions: aktivnjygomes@gmail.com

This repository holds installers only.
